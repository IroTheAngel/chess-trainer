# Chess Repertoire Trainer

Learn and drill a full chess opening repertoire in the browser: Catalan, Queen's Gambit, Vienna and the Alien and Martian Gambits as White; Caro-Kann, Slav, Sicilian and Dutch as Black. 498 lines, a spoken coach, puzzles and play against the computer.

Play it at https://irotheangel.github.io/chess-trainer/
